# Royal Family media fixes and working-folder release

## What failed in the recorded video

The preserved Royal Family export has 13 scenes and 2 accepted YouTube scenes (15.38%), against its 65% target. Its creative review found modern royal-family imagery over 1936/1952 narration, and timed out before approval. The three attempts cost $0.06645106 in total; the successful attempt cost $0.025887615. Those are historical charges, not the cost of this repair.

## Changes to the main pipeline

1. **Dated retrieval:** person, alias, place and object queries retain the scene's year/era qualifiers in their first search wave.
2. **Archive transport:** HD remains the first choice. An SD rescue (minimum 360p) is available only when the actual source title/description/channel identifies archival material and a pre-1990 year. Search-query words alone cannot activate it. Recreation, simulation and gameplay indicators cannot activate it. Downloaded cuts still require media integrity and scene/identity/era checks.
3. **Fewer repeated format requests:** source-pool download alternatives are combined into one fallback selector after the first preferred format. Authentication, private/unavailable sources and size-budget failures stop without repeating every format.
4. **Historical identity:** explicit wrong-era/year or anachronism verdicts cannot be softened into a generic portrait near match. The visual review policy version is updated so stale handoff stamps are rechecked.
5. **Review repair wiring:** anachronism, wrong era/year/period and narration contradictions request media repair rather than only a text/layout revision. Incomplete final review keeps pending media findings in the release report.
6. **Last-resort delivery:** distributed defaults now agree with the existing global-media policy: try real footage/images/stock first, then allow a script-grounded graphic for an unresolved scene. Arbitrary emergency media stays disabled. Explicit real-media-only requests remain supported. Coverage reports distinguish valid renderable assets, real media and grounded fallback scenes.
7. **Date editing:** full day-month-year dates are a single editing opportunity. Date/timeline counters use clock/data ticks instead of cash sounds.

## Cost behavior

The repair adds no paid requests. Existing structured-response and vision-result caches remain enabled; unchanged valid decisions can be reused within a resumed project. The format consolidation reduces repeated download extraction, not OpenRouter token prices. Enabling the existing terminal delivery policy avoids the specific late media-contract failure that wasted paid planning on the first two attempts. New assets, changed prompts or revisions can still need paid model calls. No claim is made that future costs are zero or that all past costs can be recovered.
